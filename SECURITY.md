# Security policy

## Supported versions

SemanticVideo is currently pre-alpha. Security fixes are applied to the latest
release and the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue for an unpatched vulnerability.

Include reproduction steps, affected versions, expected impact, and any known
mitigations. Maintainers will acknowledge a complete report as soon as
practical.
